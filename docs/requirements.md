# 需求、假設與未決事項

## 已確認

本次授權範圍是建立 starter structure 並直接放入儲存庫。功能需求尚未確認；現有名稱不能作為產品規格。

## 暫定假設

以下是可調整的工作安排，不是產品需求：

| ID | 假設 | 影響與重新檢視時機 |
| --- | --- | --- |
| A-01 | 文件先使用繁體中文 | 協作者與使用者確定後再決定是否需要英文版 |
| A-02 | 先採文件優先、無框架的骨架 | 確認交付形式後再選語言、框架與執行環境 |
| A-03 | src/ 與 tests/ 作為暫定目錄 | 技術選型後可調整，避免為保留目錄而限制架構 |
| A-04 | 初期以小範圍變更逐步推進 | 確認協作方式後再決定審查與自動化規則 |
